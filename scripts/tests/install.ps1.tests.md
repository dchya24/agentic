# Windows installer test contract

Run these checks on Windows x86_64 with Windows PowerShell 5.1 or PowerShell 7.
Every case must use a temporary `-InstallDir`, a temporary `USERPROFILE`, and a
local HTTP server that serves generated fixtures. Set
`AGENTIC_RELEASE_BASE_URL` to that server; never contact GitHub from installer
tests.

## Fixture layout

Generate these files in a temporary release directory:

- `agentic-windows-x86_64.zip`, containing
  `agentic-windows-x86_64.exe`.
- `checksums-windows.txt`, containing the SHA-256 of that zip using the same
  two-column format generated by `.github/workflows/release.yml`.

## Required cases

1. **Verified x64 install**
   - Run `scripts/install.ps1 -InstallDir <temp> -SkipPathUpdate`.
   - Assert `<temp>\agentic.exe` exists and matches the fixture executable.
2. **Checksum mismatch**
   - Put an existing marker at `<temp>\agentic.exe`.
   - Publish a deliberately incorrect checksum.
   - Assert the installer exits non-zero and the marker is unchanged.
3. **Unsupported architecture**
   - Run on Windows ARM64, or set `AGENTIC_TEST_ARCHITECTURE=Arm64` in the
     isolated test process.
   - Assert non-zero exit with an `x64` support message and no download.
4. **Config preservation**
   - Put a marker config at `%USERPROFILE%\.config\agentic\config.json`.
   - Install and assert the config bytes are unchanged.
5. **Default skips initialization**
   - Install without `-Init` and assert the fixture executable is not invoked.
6. **Explicit initialization**
   - Use a fixture executable that logs arguments.
   - Install with `-Init` and assert the logged arguments are exactly
     `config init --interactive`.
7. **Tagged version URL**
   - Run with `-Version 0.3.2` and assert requests use
     `/releases/download/v0.3.2/`.
8. **User PATH isolation**
   - Use `-SkipPathUpdate` for all tests above.
   - In a dedicated disposable Windows user, run without the switch and assert
     only the User-scope PATH changes; System-scope PATH must remain identical.

`-SkipPathUpdate` and `AGENTIC_TEST_ARCHITECTURE` are test seams. The latter is
accepted only when `AGENTIC_INSTALLER_TESTING=1` is also set.
