### Informasi Tambahan Struktur Komponen Antarmuka:

1. **Header / Brand Logo**: Menggunakan font block bergaya retro cyberpunk berwarna gradasi (Pink ke Cyan).

## Pertanyaan

1. Pertanyaan 1

untuk yang dibawah
``` text
 ⚡ sumopod/MiniMax-M2.7-highspeed  |  💬 0 msgs  |  📊 0 ↑ / 0 ↓  |  ⏱️ 0s
```

Bagian `|  💬 0 msgs  |  📊 0 ↑ / 0 ↓  |  ⏱️ 0s` sepertinya dihilangkan saja. Dan sebenarnya ini juga ada di beberapa bagian di gambar 3.


2. Pertanyaan 2

```text
agentic> who are you?                                 sumopod MiniMax-M2.7-highspeed 📌 dev
```

`agentic> who are you?` ini adalah bagian prompt users atau input users. Dan `sumopod MiniMax-M2.7-highspeed 📌 dev` ini adalah bagian metadata yang menunjukkan model AI dan branch environment yang sedang digunakan.
Bisakah bagian `sumopod MiniMax-M2.7-highspeed 📌 dev`  berada di bawah prompt users?
